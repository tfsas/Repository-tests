# My cypress Automation

This project utilizes Cypress to automate the testing of a login feature and a user updade feature. Cypress is a JavaScript-based end-to-end testing frameworks that allow developers to write tests and execute them im a real browser.

## Installatin
```bash
npm install
```
**NOTE**
>
> it is necessary to have **node** installed

## Running
```bash
# You open the Cypress UI
npx cypress open

# Run the automation by command line
npx cypress run
```
